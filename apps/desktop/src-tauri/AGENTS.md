# 桌面宿主规范

适用于 `apps/desktop/src-tauri/`，继承[桌面规范](../AGENTS.md)。涉及服务职责时同时读取 [Server 规范](../../../server/AGENTS.md)。

- 宿主负责桌面能力与进程生命周期，不复制服务端业务规则。
- 界面关闭、后台运行、退出和重启的产品语义明确，不相互替代。
- 启停、取消与资源释放有明确所有者；完成状态反映实际结果，不仅表示已发出请求。
- 失败处理保留可诊断性，不留下无人负责的工作或资源。
- 验证结论限定到实际覆盖的平台与产品行为，遵循[测试规范](../../../.agents/testing/AGENTS.md)。

涉及发布与更新资产时读取[发布技能](../../../.agents/skills/release/SKILL.md)。

## 已覆盖的稳定性行为

| 范围 | 当前处理 | 验证边界 |
| --- | --- | --- |
| 子代理身份 | 父级请求与工具标识独立可选，缺失消息 ID 时使用稳定内容摘要 | 覆盖标识组合、缺失 ID、父请求结束及内容相同但上下文不同 |
| Steer 与 Task | 原 transport 持有结果，完成结果只追加一次；取消和替换仍取消原任务 | 覆盖完成先后顺序、迟到结果、重复结果、工具混用和检查点；不代表重启恢复在途任务 |
| MCP Schema | 递归规范化整数约束，不改写实例数据中的普通数值 | 覆盖嵌套、组合约束、非整数、大整数和字面值 |
| Responses 输出 | 按输出项维护增量基线，避免多段输出丢失与重复 | 覆盖 delta、done、终态快照及空输出 |
| 思考签名 | 保持同协议签名顺序，保留 Cursor 不透明片段 | 覆盖检查点往返；不伪造或跨服务商转换未知签名 |
| Anthropic 拒绝 | refusal 终止该轮，不执行已缓冲工具 | 覆盖普通结束、长度截断、不完整 SSE 与 Cursor exec 输出 |
| OAuth 续期 | 同账号串行准备凭据，先保存续期结果，首次且尚未输出的 401 可重试 | 内置插件、共享 SDK、宿主并发/取消/写入失败；撤销授权仍需重新登录 |
| 代理配置 | 生效配置变化时重建缓存客户端 | 本地模拟代理覆盖运行中切换与读配置失败 |
| SQLite 连接 | 回收前处理回滚，残留事务的连接直接关闭 | 覆盖提交失败、未结束事务及后续写入 |
| 存储清理 | 手动清理完成后回收数据库空间 | 不新增自动保留周期，不自动删除会话 |
| 插件目录 | 入口、SDK 与 Deno 权限使用一致的真实路径 | 覆盖符号链接别名目录 |

## 桌面验证

- 固定默认窗口 820×558，紧凑字号、平面侧栏与当前应用图标。
- 全局接管开关、无确认关闭、失败状态与重复点击保护通过模拟管理 API 验证。
- 模型复制草稿、编辑、连通性测试、账号状态筛选、模型目录暂存与保存。
- 中、英、葡布局，浅色/深色主题，菜单键盘操作和嵌套弹窗。
- 年度用量显式日分桶，默认展开；缩放后图格重绘；缩小后的柱状图与悬停提示。
- TAB 仅保留默认官方直连和自定义地址，移除内置公共服务；旧公共模式一次性改为直连，自定义地址保留。

UI 验证使用演示数据或隔离数据目录，不以真实账号或系统证书操作代替可重复测试。

## 原生工具桥接（当前开发分支）

- Windows Cursor 3.25.6：真实 Cursor 窗口 + Grok 通道完成同一会话两轮验证，共 11 次模型调用、19 次工具调用，无工具错误。
- 实际覆盖 Read、Glob、Grep、Write、StrReplace、EditNotebook、TodoWrite；随机输入、结果 JSON、文本替换和 Notebook 单元均由文件核对。
- 第二轮 Todo merge 省略有效 content 文本，恢复并保留原两项内容；模型可见历史保持前缀一致，提示与工具清单在这两轮中一致。
- 安装相关自动测试覆盖官方模型配置、GPT ApplyPatch、Shell、Task、计划/问答/模式切换、图片、拒绝、取消和同文件并发编辑。Shell 另以真实本地进程返回结果验证；未通过 UI 自动化执行终端命令。
- Rust 集成测试使用实际 worker 进程与 protobuf，客户端 IO 为受控模拟；它与上面的真实 IDE 验证分别记录。
- 隔离验证窗口和服务已关闭，临时网关设置恢复，隔离认证数据清理。未替换已安装 1.1.1，也未发布新版本。

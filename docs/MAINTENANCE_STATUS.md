# 维护状态

更新日期：2026-10-21。此文记录当前源码的验证范围，不代表改动已发布到 Release。

## 原生 Agent 接入

当前源码已经移除自维护 Agent 循环、工具执行桥、提示词编译、会话 checkpoint 投影和 Agent protobuf。模型菜单、提示词、工具与执行状态改为使用本机 Cursor 原生实现，结构见[架构说明](./ARCHITECTURE.md)。

真实客户端基线：Windows Cursor **3.25.6**，commit `f0df777c412b670d09e3eaf214967d779e67c080`。

## 自动回归

统一上下文设置另在 Windows Cursor **3.26.13** 完成隔离验证：API 模型保留 200k，账号模型在同一个设置弹窗选择 1m；原生 Host 接收到 `context=1000000` 并完成响应。同一会话改为 500k 后，下一轮接收到 `500000`，两轮 conversation ID 相同且均完成。账号目录重新同步保留覆盖值。此验证使用带本地测试账号资源的确定性插件，不代表任意上游模型均支持 1m。当前 Rust 测试 178 项通过，3 项 Deno 环境测试跳过；Node 原生边界测试 3 项通过。

默认模型设置使用 Cursor 原生 `GetDefaultModel` 接口及递增更新时间，已配置时禁止服务端提示自动切回 Auto。Windows Cursor 3.25.6 隔离桌面验证通过设置卡片编辑、取消、保存、重载与新建对话；新对话直接选择 `grok-4.7`，本地确定性模型接口收到对应 ID 并完成响应。此用例验证默认路由，不作为真实 Grok 服务质量证据。新增回归覆盖设置持久化、刷新版本、Auto 提示禁用及默认模型失效；当前本地 Rust 测试 176 项通过，3 项 Deno 环境用例跳过。

- 原生路由保留 Host 的状态和回调引用，只替换模型与地址；官方模型不进入 BYOK 路径。
- 安装与恢复幂等，拒绝未知入口、损坏备份和不同数据目录的重复补丁，不用旧备份覆盖 Cursor 更新。
- 原生模型网关独立鉴权，不依赖 External API 开关；同名模型按配置隔离，密钥不出现在模型元数据中。
- OpenAI / Anthropic 协议与用量转换，Responses 自定义工具输入、签名推理数据和 system 消息。
- 用户配置的输出上限、显式思考参数与稳定的会话模板值。
- OAuth 续期、代理刷新、SQLite 事务回收、统计清理等既有基础设施回归继续保留；已移除的自维护 Agent 测试随对应实现删除。

检查命令见[维护说明](../MAINTAINING.md)与[原生接入维护](../server/native-agent/README.md)。依赖 Deno 测试环境的既有账号续期测试需要单独启用，不把跳过的用例计为通过。

## 未覆盖范围

- macOS/Linux 的安装修改与恢复、Remote SSH 和云端工作区。
- 在途子任务跨进程恢复、所有 Agent 模式、MCP 服务组合及并发工具场景。
- 各服务商的原生 WebSearch、图像生成和其他辅助 API。
- 与 Cursor 云端 Agent 的全部实验开关和行为一致性。

这些能力由原生运行时或服务商决定，不能从文件编辑闭环推断为全部通过。私有入口在 Cursor 升级后仍需回归，但 BYOK 不再维护提示词、工具定义或执行循环。

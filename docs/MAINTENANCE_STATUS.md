真实客户端基线：Windows Cursor **3.25.6**，commit `f0df777c412b670d09e3eaf214967d779e67c080`。

## 自动回归

模型列表的上下文选项仅显示容量数值和箭头，移除标签、常驻边框与“未测试”占位。项目默认工作预算为 GPT 1m、Grok 500k；API 和账号模型共用服务端规则，手动覆盖优先。隔离桌面验证五个账号模型的默认值、修改为 200k、重置及原生网关返回值一致；服务商声明的能力不会被改写。

Windows Cursor **3.26.13** 中，新型号 GPT 的思考菜单显示上游给出的档位；选择 High 后，确定性账号插件实际收到 `high`。同一会话的原生上下文详情显示约 12.1k / 400k（3%），行内改为 1m 后下一轮显示约 12.1k / 1m（1%），底层记录为 12060 / 1000000（1.206%）。验证包含原生缓存刷新、模型身份保持和账号同步保留覆盖值。未将最初缺失 effort 的复现请求计为成功用例；夹具不能证明任意上游模型都支持 1m。

默认模型入口位于模型行“测试”右侧，选中的一行显示“默认模型”；系统设置中的旧卡片已移除。账号和 API 模型的点击切换、唯一标识、持久化及刷新回读已在隔离桌面验证。底层仍使用 Cursor 原生 `GetDefaultModel` 接口及递增更新时间，已配置时禁止服务端提示自动切回 Auto；此前 Windows Cursor 3.25.6 的重载、新建对话及 `grok-4.7` 路由验证保持适用。

最近完整回归：185 项 Rust 测试通过，无跳过（包含 Deno 凭据生命周期用例）；4 项 Node 原生接入测试及 12 项 Codex 插件测试通过。前端类型检查、生产构建、完整 Windows 桌面构建与 Clippy 通过。浅色、深色布局和底部下拉菜单避让已人工检查。

- 原生路由保留 Host 的状态和回调引用，只替换模型与地址；官方模型不进入 BYOK 路径。
- 安装与恢复幂等，拒绝未知入口、损坏备份和不同数据目录的重复补丁，不用旧备份覆盖 Cursor 更新。
- 原生模型网关独立鉴权，不依赖 External API 开关；同名模型按配置隔离，密钥不出现在模型元数据中。
- OpenAI / Anthropic 协议与用量转换，Responses 自定义工具输入、签名推理数据和 system 消息。
- 用户配置的输出上限、显式思考参数与稳定的会话模板值。
- OAuth 续期、代理刷新、SQLite 事务回收、统计清理等既有基础设施回归继续保留；已移除的自维护 Agent 测试随对应实现删除。

检查命令见[维护说明](../MAINTAINING.md)与[原生接入维护](../server/native-agent/README.md)。依赖 Deno 测试环境的既有账号续期测试需要单独启用，不把跳过的用例计为通过。

## 未覆盖范围

- macOS/Linux 的安装修改与恢复、Remote SSH 和云端工作区。
- 在途子任务跨进程恢复、所有 Agent 模式、MCP 服务组合及并发工具场景。
- 各服务商的原生 WebSearch、图像生成和其他辅助 API。
- 与 Cursor 云端 Agent 的全部实验开关和行为一致性。

这些能力由原生运行时或服务商决定，不能从文件编辑闭环推断为全部通过。私有入口在 Cursor 升级后仍需回归，但 BYOK 不再维护提示词、工具定义或执行循环。

### Issue #11：Stop 与 Steer

原生 `LocalAgentClient` 收到 Host 的动作管理器，却没有启动动作消费或连接其取消信号，执行器使用空接收器。桥接现在为每个 Run 建立取消作用域，并复用原生接收器和注入记录；模型路由、工具执行、步骤循环及 checkpoint 所有权保持原有边界。

- 30 项 Node 回归通过。新增用例覆盖停止流式请求、停止模型查询、已经取消的 Run、步骤边界投递、失败清理、后续 Run 隔离，以及不支持原生结构时拒绝安装。安装器生成物一致性另行检查。
- 按用户要求使用本机 macOS Cursor **3.27.14** 验证，正式安装入口与本分支生成物一致；通过已安装的 Rust 网关 **v1.1.2** 转发至本地确定性 Responses 服务。Stop 后网关记录 `cancelled`，服务商端连接关闭；主动补发旧尾段后，下一轮的输入历史和界面回复都不含该尾段。
- Steer 通过原生界面提交，原生 Read 工具实际读取临时文件；下一次模型请求包含新的指令一次，前后两次网关调用保持同一 `run_id`，均完成。未将夹具预检或先前工具历史导致的夹具分支误判计入成功证据。
- 验证时临时固定内置 Harness；Cursor 的热更新 Harness 会绕过现有安装目录补丁，仍需单独处理。本轮不修改热更新模块，不代表所有 Harness 版本均已支持。

本轮未修改 Rust 或提供商实现；未运行 Rust 编译与桌面打包（本机无 Cargo）。可复核的请求、取消记录及脱敏摘要位于忽略目录 `target/issue11-live/`，其中 `verification.json` 汇总结果。没有真实付费模型生成，也没有发布版本。

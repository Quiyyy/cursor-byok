# Server 维护规范

适用于 `server/`，继承[顶层入口](../AGENTS.md)。审查与行为修改分别读取[审查规范](../.agents/review/AGENTS.md)和[测试规范](../.agents/testing/AGENTS.md)。`native-agent/` 继续读取[原生接入规范](native-agent/AGENTS.md)。

## 职责与调用方向

```text
src/app.rs               # 装配服务依赖与入口
src/control/              # 桌面管理 HTTP 操作
src/local_app/            # 接管、代理、证书与原生安装生命周期
src/api/byok/             # 原生和外部模型 HTTP 入口、协议选择
src/provider/             # Provider 序列化、响应事件、记录与超时边界
src/plugin/               # 账号资源、Deno Worker 与宿主网络能力
plugins/build-in/         # 各服务商的账号 / 请求适配
src/model/                # 配置、请求、消息和用量的数据类型
src/store/                # SQLite 读写与诊断数据
src/cursor/               # Cursor 服务协议及 TAB、Commit 等独立能力
```

```text
管理界面 → control → 配置 / 账号资源 / 接管操作 → 返回管理结果
模型请求 → api/byok
             ├─ 同协议 API → NativeForwarder → 上游 HTTP
             ├─ 跨协议 API → 协议投影 → ProviderRouter → Provider
             └─ 账号模型 → PluginRegistry → Deno Worker → 宿主 HTTP → 上游
           ← 对应协议响应 / 响应流 ←──────────────────────────────┘
调用记录 ← 模型连接的实际请求、响应、用量和结束事件 → store
```

- 不在 Server 重建 Cursor 的提示词、工具循环、权限批准、会话或 checkpoint。
- 不把上述路径混为一条：原生网关与 External API 有不同鉴权、开关和身份来源；同协议转发、协议投影与账号 SDK 的参数表达也不同。
- `control` 承接管理请求，不承担 Agent 执行。新业务应由职责明确的模块拥有，避免引入只转发一层的方法和无实际需要的服务框架。

## 请求与身份

- 模型配置 ID、真实上游模型 ID、会话 ID、generation / Run ID 和日志调用 ID 是不同概念；新增重试记录不得重置原生会话或缓存身份。
- 配置修改前先列出调用方显式值、保存的配置、表单默认值和传输默认值的来源。统一规则不能抹掉“未指定”“显式关闭”“显式 null”和不同对象模式的差别。
- 同协议路径保持原始请求语义；跨协议路径只做已支持的转换，不能静默丢掉工具、签名回放、调用标识或关闭选项。
- 涉及协议、前缀或原生路由时，读取 [cursor-prefix-stability](../.agents/skills/cursor-prefix-stability/SKILL.md)。遵循需求修正规则，不能仅为消除某个探针失败改变所有协议的行为。

## 生命周期、插件与记录

- 对本次改动涉及的异步任务、响应流、Worker 调用和数据库写入，说明所有者与结束条件。检查的不是函数是否叫 `cancel`，而是实际运行的工作是否接收信号和释放资源。
- 区分模型请求取消与已发出的凭据续期：续期结果可能必须保存，不能为了统一取消而丢失轮换凭据。插件资源状态、准备锁和实际模型调用分别分析。
- 重试只在已支持的错误类型、次数和输出边界内发生；已经向用户发送结果后的行为不得悄悄重放。
- 日志生命周期与实际调用一致，但日志错误的影响需单独评估。缺失收尾、统计错误与模型执行失败不能混为同一等级。
- 接管状态查询、启用、关闭和应用退出分别追踪其副作用；修改职责边界时验证真实调用方，不假定改成纯读取或加锁即可完成所有生命周期治理。
- 记录中不泄露认证头、令牌或正式账号资料。插件网络权限由宿主边界实施，不靠插件自行遵守。

## 存储与验证

- 修改表、字段、SQLx 迁移、持久化映射和数据库夹具时读取 [database-schema](../.agents/skills/database-schema/SKILL.md)。不将删除运行时代码自动扩大为删除用户数据或重写历史迁移。
- 使用隔离存储和模拟服务验证请求、响应及副作用；仅观察数据库结果不能证明远端取消，仅验证 Provider 不能证明网关参数已正确进入。
- 公共参数规则覆盖实际受影响入口；插件变更覆盖资源准备与模型请求的不同生命周期；接管变更需要联合阅读 [Tauri 规范](../apps/desktop/src-tauri/AGENTS.md)。
- 具体命令按测试规范选择。提交时说明验证过的协议、入口和平台，不以 Rust 编译通过替代核心链路验收。

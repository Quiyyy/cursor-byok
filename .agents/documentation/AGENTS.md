# 文档规范

由[顶层规范](../../AGENTS.md)按任务路由，适用于全仓文档及规范维护，不限于本目录。

- 区分现行规范、设计方案、历史记录和使用说明，明确用途与有效状态；方案、示例与历史记录不自动成为现行规范。
- 规范只声明长期适用的核心设计、职责与约束。实现描述、技术版本、调用步骤和故障处置留在对应参考资料，不作为永久设计要求。
- 通用规则集中在顶层，子规范引用并补充自身差异；同一规则不在多处完整复制，局部约束不推广为全局要求。
- 普通修复不自动追加全局规则。清理失效描述时保留仍有效的需求与约束，不以篇幅决定内容去留。
- 历史材料保留日期、适用范围与当时事实，不为迎合当前实现改写历史。不能解析的历史路径保留为文字，不伪造当前位置。
- 新增、移动或删除文档时同步导航、引用与相关附件，维护单一有效入口。
- 变更规范时消除适用规则间的矛盾；完成[顶层规范](../../AGENTS.md)要求的提交前自检。文档验证遵循[测试规范](../testing/AGENTS.md)。
